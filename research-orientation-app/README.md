# Research Methodology Orientation — interactive bilingual book for DIET faculty, Karnataka
# ಸಂಶೋಧನಾ ವಿಧಾನ ದೃಷ್ಟಿಕೋನ ತರಬೇತಿ — ಡಯಟ್ ಉಪನ್ಯಾಸಕರಿಗಾಗಿ ದ್ವಿಭಾಷಾ ಸಂವಾದಾತ್ಮಕ ಪುಸ್ತಕ

A 60-hour, 12-chapter orientation built from the master prompt, with worked examples from Karnataka's
Department of School Education and Literacy (DSERT, DIETs, CRCs/BRCs, SATS, LBA, HPC, Sethubandha,
Kalika Chetarike, Nali Kali, KPS bilingual sections, SDMCs, Chinnara Angala, NAS/PARAKH).

Part II tools run in the browser on sample data or the user's own pasted data: alignment matrix, AI prompt
planner with responsible-use checklist and disclosure statement, data screening (missing, out-of-range,
straight-lining, outliers, skewness/kurtosis, Cronbach's alpha), technique chooser, exploratory factor analysis
(KMO, Bartlett, scree plot, principal axis factoring with varimax), CFA reliability and validity (CR, AVE,
Fornell–Larcker), SEM fit checker with an APA sentence, and bootstrap mediation. The EFA, KMO, Bartlett and alpha
calculations are checked against numpy. Each part has its own certificate.

Each chapter is a set of pages: opener with objectives → lessons → "From Karnataka classrooms" examples →
activity (with an embedded tool and a response sent to the facilitator desk) → quiz with feedback.

**Bilingual reading.** Every chapter, example, activity and quiz exists in English and Kannada.
Readers switch between English, ಕನ್ನಡ, or both side by side (default). Menus are shown in both languages.

**21 research tools** (13 in Part I, 8 in Part II). Part I tools: research question builder, ethics decision tree, sample size calculator, statistics
workbench (descriptives, Welch and paired t-tests, one-way ANOVA, chi-square, Pearson r — with p-values and
effect sizes), survey builder, qualitative coding practice, mixed-methods design selector with joint display,
action research journal, classroom observation timer, stakeholder map, proposal builder (Word export / print),
APA reference manager, quality checklist.

**Also:** pre-assessment, progress tracking, badges, points and day streaks, bookmarks, notes, full-text search
(English and Kannada), resource library with nine downloadable Word (.docx) templates with English and Kannada headings
(parent consent form, child assent script, teacher interview guide, observation schedule, proposal outline,
action research planner, codebook, policy brief, peer review checklist), glossary of Karnataka terms, facilitator desk (cohort
table, chapter analytics, CSV export, feedback on submissions), printable certificate, text size, high-contrast
mode, backup/restore, offline use (PWA).

## Online version (accounts, saved work, live cohort)
Hosted on Netlify from a private repository (or on GitHub Pages while the repository is public), with a free
Supabase database. Follow **[SETUP.md](SETUP.md)** (about 30 minutes, once). Online, the book is **invite-only**: people sign in
with email and password, an account can be created only for an email the administrator has added in
*Access control*, and removing an email stops access at once. Online, progress, notes, journal, proposal and activity responses are saved online and merged across
devices; facilitators see the real cohort, give feedback and post announcements; every chapter has a
discussion board. Database rules (`supabase/schema.sql`) keep each participant's work private.

**Every tool has a download** of the participant's own work, and that work is kept between visits (on the device, and online when signed in).

**Downloads (all versions):** certificate, any chapter, the whole book (53 pages), a personal portfolio,
the action research journal, reference list, survey, proposal, nine templates (.docx); observation counts,
interview codes and cohort report (CSV); statistics results (.txt).

## Run it
```bash
npm install
npm run dev          # local development
npm test             # statistics and content-parity tests
npm run build        # PWA build in dist/
npm run build:single # one self-contained HTML file: dist/single/research-orientation.html
```
The standalone file is not kept in this public repository, so that only invited people can read the book; build it
with `npm run build:single` when needed. It can be shared by email or pen drive and opened in any browser without internet
(fonts fall back to system fonts offline).

## Notes for the Department
- Figures inside worked examples are **illustrative teaching data** unless a source is named; the page says so.
  Statements about State evidence come from the background notes in this repository's `rewrites/` folder.
- The Kannada text is a careful first translation; it should be reviewed by a DSERT language editor before
  wide release. Tool screens (calculators, forms) have bilingual titles but English working labels.
- Downloads (templates, proposal and survey as .docx, CSV report, progress backup) use the viewer's
  download prompt when the book is published on claude.ai, and a normal browser download elsewhere.
- Without the online setup (claude.ai copy, standalone HTML), work stays in the browser and the facilitator
  desk shows a sample cohort. Not yet built: direct messaging, mentorship, video library, leaderboards, Hindi.
- Content lives in `src/data/modules.ts` (English) and `src/data/modules.kn.ts` (Kannada). A test fails if the
  two editions drift apart.
