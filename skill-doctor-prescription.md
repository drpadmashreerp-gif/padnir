# Skill Doctor Prescription (2 Nov 2026)

## Diagnosis
- About 1,300 skill files from about 120 org-synced plugins; about 900 skill names are listed at the start of every session.
- More than 70 connectors fail to connect in every session.
- Several plugins add startup messages to every session (e.g. SweetClaude).
- Duplicate skills: four "de-AI writing" skills, three proofreading skills.

indian-hc-drafting, supreme-court-drafting, model-builder, aws-data-analytics, datarobot, clickhouse, tableau, holistics, sanity, docker-skills, signalwire, geoai, bio-research, brightdata, nimble, sharedbrief, founderos, strategy-consultant, management-consulting, social-media-skills, editorial-os, govtribe, cineflo, runway-api, creative-claw, sweetclaude, zizi-skills, wiser, ai-employees, engineering, data, design.

## Remove duplicates
- Keep one of: humanizer, humanize-kit, anti-ai-writing, anthropic-skills:humaniser.
- Keep one of: proofread, copy-editing:proofread.

## Expected result
Faster session start, no SweetClaude startup message, and roughly 80–90% fewer skills listed in every session.

## How
These plugins are synced from the claude.ai organisation. Switch them off in the claude.ai plugin/connector settings. If a plugin is locked, an organisation admin must switch it off.
